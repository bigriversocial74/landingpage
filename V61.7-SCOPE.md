# North Mountain Media Visual Page Editor v61.7

## Editor experience

- Canvas-first editing modeled after modern hosted website builders.
- Click live headings, copy, and supported block content to edit it in place.
- Contextual section and block toolbars for design, duplicate, move, image, add block, and delete actions.
- Complete inspector controls for typography, colors, backgrounds, overlays, spacing, sizing, image placement, visibility, responsive behavior, and reusable content.
- Section image upload and replacement directly from the page canvas.
- Desktop, tablet, and mobile preview modes.

## Sidebar cleanup

- Pages, Sections, Blocks, and Design only.
- Layers removed.
- Page dropdown removed.
- Stacked editor-tool menu removed.
- Sidebar library promotion, chips, and drag-and-drop panel removed.
- Plain navigation and list controls replace boxed sidebar buttons.

## Templates

- Studio Split
- Centered Launch
- Editorial Story
- Platform Showcase

Each template has a materially different section structure, typography direction, content flow, proof section, and conversion path.

## Mobile templates

- Responsive section stacking and typography.
- Hamburger button in mobile preview and published pages.
- Configured navigation loads inside an off-canvas sidebar drawer.
- Drawer includes site identity, navigation, optional CTA, backdrop close, Escape close, and resize cleanup.

## Deployment

No SQL migration is required. Preserve live `config.php` and the complete `storage/` directory.
