# Unified Social Inbox v66D Scorecard

## Initial score: 6.7/10

Existing communication engines were already strong, but operators had to work across separate Communications, POD Messaging, Blog moderation, Leads, Call Center, and Notifications screens.

## Repair target

- Normalize existing source records without duplicating message content.
- Preserve source ownership, security, visibility, and native read behavior.
- Add one operator workspace with search, channel filters, queues, preview, and native-source links.
- Add shared assignment, priority, workflow status, needs-response, pinning, snooze, and notes.
- Add per-administrator read override and archive state.
- Deduplicate notifications already represented by calls, comments, or messages.
- Keep the POD fully functional without a HomeServer.
- Expose stable HomeServer capability boundaries for private summaries and suggested replies.
- Validate source, browser behavior, cleanup, MySQL 8.4, MariaDB 11.4, and retained portal quality.
