# North Mountain Media Chat Knowledge Base

This folder contains the local knowledge used by the portfolio chat interface.

## Structure

- `knowledge-base.json` — structured data for backend or API integrations.
- `knowledge-base.js` — browser-ready copy used by the current no-backend chat.
- `resume.md` — full professional resume knowledge.
- `founder-profile.md` — background, strengths, positioning, and contact information.
- `projects/` — individual project briefs.
- `case-studies/` — longer Microgifter and Gruber case studies.

The current website performs lightweight local keyword and phrase matching in the browser.
A future server-side AI integration can load the Markdown or JSON documents as retrieval context.
